## 2025-03-02 - PWA Installation Instructions
**Learning:** Replacing browser `alert()` with an integrated UI for PWA instructions significantly improves UX by maintaining the app's visual context and professional feel. When adding such helpers, ensuring they remain under 50 lines requires prioritizing concise, multi-platform instructions over platform-specific high-fidelity assets (like custom icons).
**Action:** Use integrated UI overlays instead of native dialogs for instructional fallbacks, and use semantic lists to handle multiple platforms efficiently within line constraints.
