## 2025-05-15 - Multi-platform PWA Guidance
**Learning:** For PWA installation on non-Chromium platforms (like iOS Safari), providing a themed in-app instruction card using visual icons (e.g., Share, Menu) instead of native browser alerts maintains brand consistency and improves guidance.
**Action:** Always provide a visual 'How-to' modal or card for iOS PWA installation to replace generic browser alerts.
