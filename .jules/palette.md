## 2025-05-15 - Enhanced PWA Installation UX for iOS/Safari
**Learning:** Standard browser `alert()` calls for PWA installation instructions are jarring and inaccessible. Providing a themed, step-by-step UI with visual icons (Share, SquarePlus) that match the OS interface significantly improves the user experience and success rate of app installation.
**Action:** Always prefer custom, branded instruction components over native alerts for platform-specific onboarding or installation flows.
