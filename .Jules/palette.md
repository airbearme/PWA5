## 2025-05-15 - Improving PWA Onboarding for iOS
**Learning:** For PWA installation on non-Chromium platforms (like iOS Safari), providing a themed in-app instruction card using visual icons (e.g., Share, Menu) is significantly more delightful and less disruptive than using native browser alerts.
**Action:** Always prefer themed UI components over native `alert()` or `confirm()` for guidance flows to maintain brand consistency and provide better visual context (like icons of the specific buttons users need to look for).
